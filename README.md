# NANAIRO — 七色カードパーティー

家族 2〜10人（今回の本番は **7人**）で、スマホのブラウザから同じルームに入って遊ぶ UNO 風カードゲームです。

アプリのインストールは不要です。Safari / Chrome を開くだけです。

---

## 今日、7人で遊ぶ（いちばん簡単な方法）

1台のパソコンをホストにして、家族のスマホを同じ Wi-Fi に繋ぎます。

```bash
npm install
npm start
```

`npm start` は画面のビルドも一緒に行います。GitHub から別PCへ持ってきたあとは、**必ずそのPCで** 上を実行してください（`dist` は GitHub に含まれません）。

起動すると、ターミナルに次のような URL が出ます。

```text
Local:   http://localhost:3001
Phone:   http://192.168.x.x:3001
```

**Phone の URL を家族のスマホで開いてください。**

1. 誰か1人が「ゲームを作る」→ 4文字のルームコード（例: `AB7K`）が出る
2. 残りの6人がニックネームとコードを入れて参加
3. ホストがチーム戦 ON / 🎲 ランダムチーム →「ゲーム開始」

同じ Wi-Fi に繋がらない場合は、下の「インターネット経由」を見てください。

---

## 遊び方

初めてなら、ホームの **「デモプレイを見る」** が1分でルールを見せます。途中でいつでも終了できます。

1. 自分の番になったら、場と同じ **色** か **数字 / 種類** のカードを出す
2. **同じ数字**（例: 赤7・青7・緑7）はまとめて出せます。スキップ / リバース / +2 / ワイルドはまとめて出せません
3. 出せないときは「カードを引く」。引いたカードが出せるならそのまま出せます
4. **+2 / +4 はスタック**できます。次の人が同じように +2 か +4 を出せば、引き枚数を押し返します（+2 のあと +4 も可）。出せなければ合計枚数を引いて番が終わります
5. ワイルドは色を選びます
6. 手札が 1〜2 枚になったら **UNO!** を押す。残り1枚なのに言わないと、約3秒だけ他の人に **「UNO言ってない！」** を押されます。成功するとその人は **+1枚**
7. 手札 0 枚で勝ち。チーム戦は **チームの誰かが上がったらチーム勝ち**
8. 終わったら「もう一回！」または「ロビーへ戻る」

画面中央の大きな文字と、下の短い通知で「今なにが起きたか」が分かります。

## パーティモード

ロビーで **パーティ** を選ぶと、特殊カードと試合ごとの「今日のルール」が入ります。山札も7人向けに少し厚くなります。**クラシック** は 108 枚の基本山札のままです。

| カード | 効果 |
| --- | --- |
| GIFT | 手札1枚を指名した人へ |
| POINT | 指名した人が2枚引く |
| PASS | 全員の手札が隣へ移動 |
| SPY | 指名した人の手札を1枚だけ見る |
| BOMB | 次の人が実質2枚増える |
| KING | 次の番の人を指名 |
| SWAP | 指名した人と手札を交換 |
| CHAOS | 枚数はそのまま配り直し |

特殊カードはいつでも出せます。タップで対象を選び、長押しで説明が出ます。
同じ数字の複数出し・+スタック・UNO指摘は、クラシックでも使えます。

## 開発用コマンド

```bash
npm install
npm run dev          # サーバー :3001 + フロント :5173
npm test
npm run typecheck
npm run lint
npm run build
npm start            # 本番相当（build 後の dist を配信）
```

開発中にスマホから触るときは `http://<PCのIP>:5173` ではなく、**build + start の :3001** を推奨します（1つのURLで完結するため）。

---

## 環境変数

| 変数 | 説明 | デフォルト |
| --- | --- | --- |
| `PORT` | サーバーのポート | `3001`（使用中なら 3002 / 8080 へ自動で切り替え） |

データベースは使いません。ゲーム中の状態はメモリ上に保持されます。サーバーを止めるとルームは消えます。

## インターネット経由（家の Wi-Fi が分かれているとき）

ホストPCで `npm start` したあと、別ターミナルでトンネルを張ります。

```bash
npx --yes cloudflared tunnel --url http://localhost:3001
```

または [ngrok](https://ngrok.com/) :

```bash
ngrok http 3001
```

表示された `https://...` を家族に共有します。

クラウドに載せる場合は、ビルド済み Node アプリとして **1つのポート** で配信できます。

```text
npm install
npm run build
npm start
```

`PORT` はホスト側が渡す値を使います。例: Render / Railway / Fly.io。

---

## ルール要約

- 人数: 2〜10人（7人同時接続を想定）
- 初期手札: 7枚
- 数字 0–9 / スキップ / リバース / +2 / ワイルド / ワイルド+4
- 2人のときのリバースは「もう一度自分の番」（スキップ相当）
- ゲームルールの判定は **サーバーだけ** が正しいとします
- 他人の手札は画面にも通信にも出ません

---

## トラブル

- スマホで開けない → 同じ Wi-Fi か確認。Windows のファイアウォールでポート 3001 を許可
- 「接続が切れました」→ 自動で再接続します。同じスマホならリロードしても席に戻れます
- 誰かの番で止まった → 切断中は約20秒、通常は約90秒で自動的に1枚引いてパスします

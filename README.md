# NANAIRO — 七色カードパーティー

家族 2〜10人で、スマホのブラウザから同じルームに入って遊ぶ UNO 風カードゲームです。

アプリのインストールは不要です。Safari / Chrome を開くだけです。

---

## 必要なもの

- ホスト用のパソコン 1台（Windows / Mac / Linux）
- [Node.js 20 以上](https://nodejs.org/)（LTS でOK）
- 家族のスマホ（同じ Wi-Fi がいちばん簡単）

---

## 起動（いちばん簡単な方法）

GitHub から取ってきたあと、**ホストにするパソコンで** 次を実行します。

```bash
npm install
npm start
```

`npm start` は画面のビルドも一緒に行います。`dist` は GitHub に含まれないので、別PCへ持ってきたあとは **必ずそのPCで** 上を実行してください。

起動すると、ターミナルに次のような URL が出ます。

```text
Local:   http://localhost:3001
Phone:   http://192.168.x.x:3001
```

**Phone の URL を家族のスマホで開いてください。** `:3000` や Hyper-V の `172.23.x.x` は使わないでください。

1. 誰か1人が「ゲームを作る」→ 4文字のルームコード（例: `AB7K`）が出る
2. 残りの人がニックネームとコードを入れて参加
3. ホストがロビーで設定して「ゲーム開始」

---

## ロビーの設定

ホストだけが変更できます。すぐ終わってしまうときは **カードの量** を上げてください。

### ゲームモード

| 設定 | 内容 |
| --- | --- |
| クラシック | 108枚の基本山札。特殊カードなし |
| パーティ | 特殊カードと、試合ごとの「今日のルール」が入ります |

### カードの量

試合が短いと感じたら、ここを上げます。手札と山札の数字カードが増えます。

| 設定 | 手札 | 山札 |
| --- | --- | --- |
| すくない | 5枚 | いつもの量 |
| ふつう | 7枚 | いつもの量 |
| おおい | 9枚 | 数字カードを多めに追加 |
| とてもおおい | 11枚 | さらに厚い山札 |

7人で遊ぶなら、まずは **おおい** がおすすめです。

### 特殊カード

| 設定 | 内容 |
| --- | --- |
| ふつう | パーティの特殊カードはいつもの量 |
| たくさん | KING / GIFT / SWAP などがかなり多く出ます（自動でパーティモード） |

### チーム

個人戦かチーム戦を選べます。チーム戦は **チームの誰かが上がったらチームの勝ち** です。同じ数字の同時出しは、チーム戦でも使えます。

---

## 遊び方

初めてなら、ホームの **「デモプレイを見る」** でルールを確認できます。ページは自動では進みません。**次へ** で進み、いつでも終了できます。

1. 自分の番になったら、カードを **タップして選ぶ** → 説明が出る → **「このカードを出す」** を押す。場と同じ **色** か **数字 / 種類** なら出せます
2. **同じ数字**（例: 赤7・青7・緑7）はまとめて出せます。出せる7が1枚でもあれば、他の色の7も光ります。まとめて選んで「枚出す」を押してください
3. 出せないときは「カードを引く」。引いたカードが出せるならそのまま出せます
4. **+2 / +4 はスタック**できます。次の人が同じように +2 か +4 を出せば、引き枚数を押し返します（+2 のあと +4 も可）。出せなければ合計枚数を引いて番が終わります
5. ワイルドは色を選びます
6. 手札が 1〜2 枚になったら **UNO!** を押す。残り1枚なのに言わないと、約3秒だけ他の人に **「UNO言ってない！」** を押されます。成功するとその人は **+1枚**
7. 手札 0 枚で勝ち。チーム戦はチームの誰かが上がったらチーム勝ち
8. 終わったら「もう一回！」または「ロビーへ戻る」

誰かがカードを出すと、画面中央にカード名と日本語の説明が出ます（例: KING → 次に遊ぶ人を指名）。場のカードをタップしても説明を見られます。

## パーティの特殊カード

| カード | 効果 |
| --- | --- |
| GIFT | 手札1枚を指名した人へ |
| POINT | 指名した人が2枚引く |
| PASS | 全員の手札が隣へ移動 |
| SPY | 指名した人の手札を1枚だけ見る |
| BOMB | 次の人が実質2枚増える |
| KING | 次の番の人を指名 |
| SWAP | 指名した人と手札を交換 |
| CHAOS | 枚数はそのまま配り直し |

特殊カードはいつでも出せます。カードをタップすると説明が出ます。出すときは **「このカードを出す」** を押します。
同じ数字の複数出し・+スタック・UNO指摘は、クラシックでも使えます。

## インターネット経由（家の Wi-Fi が分かれているとき）

ホストPCで `npm start` したあと、別ターミナルでトンネルを張ります。

```bash
npx --yes cloudflared tunnel --url http://localhost:3001
```

または [ngrok](https://ngrok.com/) :

```bash
ngrok http 3001
```

表示された `https://...` を家族に共有します。

クラウドに載せる場合は、ビルド済み Node アプリとして **1つのポート** で配信できます。

```text
npm install
npm run build
npm start
```

`PORT` はホスト側が渡す値を使います。例: Render / Railway / Fly.io。

## 開発用コマンド

```bash
npm install
npm run dev          # サーバー :3001 + フロント :5173
npm test
npm run typecheck
npm run lint
npm run build
npm start            # 本番相当（build 後の dist を配信）
```

開発中にスマホから触るときは `http://<PCのIP>:5173` ではなく、**build + start の :3001** を推奨します（1つのURLで完結するため）。

### 環境変数

| 変数 | 説明 | デフォルト |
| --- | --- | --- |
| `PORT` | サーバーのポート | `3001`（使用中なら 3002 / 8080 へ自動で切り替え） |

データベースは使いません。ゲーム中の状態はメモリ上に保持されます。サーバーを止めるとルームは消えます。

---

## ルール要約

- 人数: 2〜10人（7人同時接続を想定）
- 初期手札: ロビーの「カードの量」で 5 / 7 / 9 / 11 枚
- 数字 0–9 / スキップ / リバース / +2 / ワイルド / ワイルド+4
- 2人のときのリバースは「もう一度自分の番」（スキップ相当）
- ゲームルールの判定は **サーバーだけ** が正しいとします
- 他人の手札は画面にも通信にも出ません

---

## トラブル

- スマホで開けない → 同じ Wi-Fi か確認。Windows のファイアウォールでポート 3001 を許可
- 「接続が切れました」→ 自動で再接続します。同じスマホならリロードしても席に戻れます
- 誰かの番で止まった → 切断中は約20秒、通常は約90秒で自動的に1枚引いてパスします
- すぐ終わる → ロビーで **カードの量** を「おおい」または「とてもおおい」にする
- 特殊カードを増やしたい → ロビーで **特殊カード：たくさん**
- 同じ数字が光らない / 同時に出せない → 出せる色の数字が1枚でもあれば、他の色の同じ数字も光ります。まとめて選んで「枚出す」を押してください
